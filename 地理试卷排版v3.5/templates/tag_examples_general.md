# 通用结构打标案例

> 供 `tag_structure` (Step2) 参考。包含不区分题型的通用结构识别规则。
> **始终加载**：表格材料（segments）、注意事项（notes_items）、分区标题（instructions）是几乎所有试卷都会出现的结构。

---

## 案例1：含表格的材料 — segments 结构

### 原文（content.md 中的占位符）

```
下表为某地区2020-2024年人口迁移数据统计表。

{{table:table_001}}

（注：表中数据为年末统计值）
```

> `{{table:table_NNN}}` 是 Step1 生成的表格占位符。对应表格的结构化数据在 `{工作目录}/清洗产物/tables.json` 中，需读取后原样复制到 segments。

### tables.json 中的表格数据

```json
{
  "tables": [
    {
      "table_id": "table_001",
      "rows": 5,
      "cols": 4,
      "data": [
        ["年份", "迁入人口（万人）", "迁出人口（万人）", "净迁移率（%）"],
        ["2020", "12.5", "8.3", "+4.2"],
        ["2021", "15.2", "9.1", "+6.1"],
        ["2022", "18.6", "10.5", "+8.1"],
        ["2023", "22.3", "12.8", "+9.5"]
      ],
      "spans": []
    }
  ]
}
```

### 标准标注

```json
{
  "id": "material_005",
  "content": "",
  "guide_sentence": "完成下列要求。",
  "segments": [
    {
      "type": "text",
      "content": "下表为某地区2020-2024年人口迁移数据统计表。"
    },
    {
      "type": "table",
      "data": {
        "rows": 5,
        "cols": 4,
        "data": [
          ["年份", "迁入人口（万人）", "迁出人口（万人）", "净迁移率（%）"],
          ["2020", "12.5", "8.3", "+4.2"],
          ["2021", "15.2", "9.1", "+6.1"],
          ["2022", "18.6", "10.5", "+8.1"],
          ["2023", "22.3", "12.8", "+9.5"]
        ],
        "spans": []
      }
    },
    {
      "type": "text",
      "content": "（注：表中数据为年末统计值）"
    }
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **识别占位符** | `{{table:table_NNN}}` 是表格占位符，去 `tables.json` 找对应数据 | 丢弃占位符或当作文本 |
| **使用 segments** | 材料包含文本+表格+文本的混合内容，必须使用 `segments` 数组 | 把表格强行转成纯文本 |
| **content 为空** | 当使用 `segments` 时，`content` 字段留空 `""` | 同时填写 `content` 和 `segments` |
| **spans 原样复制** | 将 `tables.json` 中的 `rows`、`cols`、`data`、`spans` 全部原样复制 | 忽略 `spans` 字段或修改数据 |
| **表格顺序** | 按"文本→表格→文本"的原文出现顺序排列 | 把表格放到最前面 |
| **注解放 segments** | "（注：...）"是表格的补充说明，作为独立的 text segment | 放在表格 data 中 |

## 案例1B：含合并单元格的表格 — spans 字段

### tables.json 中的表格数据

```json
{
  "tables": [
    {
      "table_id": "table_002",
      "rows": 5,
      "cols": 4,
      "data": [
        ["类别", "", "数量", "占比（%）"],
        ["人口迁入", "城镇", "1250", "45.2"],
        ["", "乡村", "890", "32.1"],
        ["人口迁出", "城镇", "560", "20.2"],
        ["", "乡村", "780", "28.1"]
      ],
      "spans": [
        {"row": 0, "col": 0, "rowspan": 1, "colspan": 2},
        {"row": 1, "col": 0, "rowspan": 2, "colspan": 1},
        {"row": 3, "col": 0, "rowspan": 2, "colspan": 1}
      ]
    }
  ]
}
```

> **说明**：`data` 是完整的 rows×cols 网格（每个位置都有文本，合并区域留空），`spans` 描述了3处合并：
> - 第0行第0列横向合并2列（"类别"跨2列）
> - 第1行第0列纵向合并2行（"人口迁入"跨2行）
> - 第3行第0列纵向合并2行（"人口迁出"跨2行）

### 对应的 segments 标注

```json
{
  "type": "table",
  "data": {
    "rows": 5,
    "cols": 4,
    "data": [
      ["类别", "", "数量", "占比（%）"],
      ["人口迁入", "城镇", "1250", "45.2"],
      ["", "乡村", "890", "32.1"],
      ["人口迁出", "城镇", "560", "20.2"],
      ["", "乡村", "780", "28.1"]
    ],
    "spans": [
      {"row": 0, "col": 0, "rowspan": 1, "colspan": 2},
      {"row": 1, "col": 0, "rowspan": 2, "colspan": 1},
      {"row": 3, "col": 0, "rowspan": 2, "colspan": 1}
    ]
  }
}
```

## 案例2：注意事项识别与拆分

### 原文

```
注意事项：
1.本试卷共6页，满分100分，时间75分钟。
2.答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。
3.回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。
4.作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。
5.考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。
```

### 标准标注

```json
{
  "notes": "注意事项：1.本试卷共6页，满分100分，时间75分钟。2.答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。3.回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。4.作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。5.考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。",
  "notes_items": [
    {"type": "title", "content": "注意事项"},
    {"type": "item", "number": "1", "content": "本试卷共6页，满分100分，时间75分钟。"},
    {"type": "item", "number": "2", "content": "答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。"},
    {"type": "item", "number": "3", "content": "回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。"},
    {"type": "item", "number": "4", "content": "作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。"},
    {"type": "item", "number": "5", "content": "考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。"}
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **双格式保留** | `notes` 保留原文全文（兼容旧格式），`notes_items` 提供结构化版本 | 只保留一种格式 |
| **标题项** | "注意事项"作为 `{type: "title"}` 项 | 把"注意事项"混入第1条的 `content` |
| **内容不含序号** | `content` 字段不含序号前缀（如"1."），序号在 `number` 字段中 | `content` = "1.本试卷..."（序号重复） |
| **序号在 number 字段** | `number` = "1"、"2"... 为纯数字字符串 | `number` = "(1)" 或缺失 |

## 案例3：分区标题与引导语合并

### 原文

```
一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。
```

### 标准标注

```json
{
  "id": "section_001",
  "type": "选择题",
  "title": "一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。",
  "instructions": []
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **标题与引导语在同一段** | "在每小题给出的四个选项中..."与题型标题在同一段落，合并到 `title` 字段 | 把"在每小题..."拆到 `instructions` |
| **instructions 为空** | 引导语不单独成段时，`instructions` 为 `[]` | 无论如何都往 `instructions` 里加内容 |

**对比：当引导语单独成段时**：

```
一、选择题：本题共15小题，每小题3分，共45分。

在每小题给出的四个选项中，只有一项是符合题目要求的。
```

此时应标注为：

```json
{
  "title": "一、选择题：本题共15小题，每小题3分，共45分。",
  "instructions": ["在每小题给出的四个选项中，只有一项是符合题目要求的。"]
}
```

## 案例4：卷标题与题型标题（header_blocks 使用）

### 场景A：仅有卷标题，无题型标题（如重庆部分区高一期末）

```
第I卷（选择题共60分）

本卷共30个小题。每小题2分，共60分。在每小题给出的四个选项中，只有一项是最符合题目要求的。
```

### 标准标注

```json
{
  "id": "section_001",
  "type": "选择题",
  "header_blocks": [
    {"type": "volume_title", "content": "第I卷（选择题共60分）"}
  ],
  "title": "",
  "instructions": ["本卷共30个小题。每小题2分，共60分。在每小题给出的四个选项中，只有一项是最符合题目要求的。"]
}
```

### 场景B：仅有题型标题，无卷标题（最常见）

```
一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。
```

### 标准标注

```json
{
  "id": "section_001",
  "type": "选择题",
  "header_blocks": [],
  "title": "一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。",
  "instructions": []
}
```

### 场景C：两者共存（卷标题 + 题型标题）

```
第I卷（选择题 共48分）

一、选择题：本题共16小题，每小题3分，共48分。在每小题给出的四个选项中，只有一项是符合题目要求的。
```

```json
{
  "id": "section_001",
  "type": "选择题",
  "header_blocks": [
    {"type": "volume_title", "content": "第I卷（选择题 共48分）"}
  ],
  "title": "一、选择题：本题共16小题，每小题3分，共48分。在每小题给出的四个选项中，只有一项是符合题目要求的。",
  "instructions": []
}
```

### 场景D：卷标题 + 注意事项（含标题和编号条目）

```
第II卷（非选择题 共40分）

注意事项：
1. 本卷共2个小题，共40分。
2. 请用0.5毫米黑色签字笔将答案写在答题卡上。
3. 考试结束后，将答题卡和试卷一并交回。
```

```json
{
  "id": "section_002",
  "type": "非选择题",
  "header_blocks": [
    {"type": "volume_title", "content": "第II卷（非选择题 共40分）"},
    {"type": "notes", "content": "注意事项：\n1. 本卷共2个小题，共40分。\n2. 请用0.5毫米黑色签字笔将答案写在答题卡上。\n3. 考试结束后，将答题卡和试卷一并交回。"}
  ],
  "title": "",
  "instructions": [],
  "questions": [...]
}
```

> **notes 格式说明**：标题 `"注意事项："` 单独占行，每个条目以序号 `1.` / `2.` / `3.` 开头，以 `\n` 分隔。也支持单行写法 `"注意事项：1. 条目一2. 条目二"`，排版代码会自动按序号拆分。

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **卷标题** | "第I卷""第II卷""第Ⅲ卷" → `header_blocks[].type: "volume_title"` | 填入 `title` 或忽略 |
| **分区内注意事项** | 分区内的注意事项 → `header_blocks[].type: "notes"` | 与文档级 `meta.notes_items` 混淆 |
| **顺序保真** | `header_blocks[]` 严格按原文顺序排列 | 重排或合并不同位置的块 |
| **两者共存** | 卷标题 + 题型标题 → 卷标题在 header_blocks，题型标题在 title | 只保留一个，丢弃另一个 |
| **仅有卷标题** | `header_blocks[]` 含 volume_title，`title` 填空字符串 `""` | `title` 不填（Schema 要求必填） |
| **无头部块** | `header_blocks: []`（空数组，不可省略） | 省略 `header_blocks` 字段 |
| **排版样式** | volume_title → "第几卷"，notes → "注意事项内容"，instructions → "Body Text" | 用同一个样式渲染所有块 |
