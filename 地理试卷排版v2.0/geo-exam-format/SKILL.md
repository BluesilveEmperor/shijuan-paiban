# 地理试卷排版 Skill（子 skill）

> **本 skill 是 [geo-exam-formatting](../SKILL.md) 主 skill 的子 skill 之一。**
> 由主 skill 的 AI 主导编排，按"清洗→打标→排版"流程依次触发各子 skill。
> 本 skill 也可独立使用，此时输出路径由用户自行指定。

## 概述

本 skill 是"地理试卷排版"流程的第三步（最终步）。接收打标输出的
tagged.json 和模板 template.dotx，生成排版好的 docx 文件。

**输入**：
- tagged.json（由 geo-exam-tag 产出）
- template.dotx（模板文件）
- images/（图片目录，由 geo-exam-tag 产出）

**输出**：
- formatted.docx（排版后的文档）
- format_log.txt（排版日志）
- quality_report.txt（质检报告，包含结构统计、规则使用、媒体统计和警告信息）

## 使用方法

```bash
python scripts/format_docx.py --json tagged.json --template assets/template.dotx --output formatted.docx
```

### 参数说明

- `--json`：打标 JSON 文件路径（必填）
- `--template`：模板 dotx 文件路径（必填）
- `--output`：输出 docx 文件路径（必填）
- `--images-dir`：图片目录（可选，默认与 JSON 文件同目录的 images/）
- `--log`：日志文件路径（可选，默认与输出文件同目录）

## 模板样式

模板包含21种预定义样式，关键样式如下：

| 样式ID | 样式名称 | 中文字体 | 字号 | 对齐 |
|--------|----------|----------|------|------|
| 18 | 考试名称 | 宋体 | 18磅(小二) | 居中 |
| 19 | 科目名称 | 黑体 | 24磅(一号) | 居中 |
| 17 | 题型标题 | 黑体 | 14磅(四号) | - |
| 4 | Body Text | 楷体 | 14磅(四号) | - |
| 1 | Normal | 宋体 | 14磅(四号) | 左对齐 |
| 11 | Table Grid | - | - | 两端对齐 |
| 6 | footer | 宋体 | 12磅(小四) | 左对齐 |
| 7 | header | 宋体 | 9磅(小五) | 两端对齐 |

### 页面设置

- 纸张：A4（21cm x 29.7cm）
- 边距：上2.54cm 下2.54cm 左1.9cm 右1.9cm
- 分栏：1栏

## 排版规则

### 文档结构

```
考试名称（样式18，居中）
科目名称（样式19，居中，"地  理"）
[空行]
分区标题（样式17，如"一、选择题：..."）
  题组
    材料（样式4，楷体）
    [图片]（居中）
    [表格]（Table Grid样式）
    引导语（样式4）
    题干（Normal，"1.题干内容"）
    [子选项①②③④]（Normal）
    选项（Normal，按规则1-5排版）
  题组...
分区标题（样式17，如"二、非选择题：..."）
  题组
    材料（样式4）
    非选择题标题（Normal，"17.阅读图文材料..."）
    子问题（Normal，"（1）..."）
```

### 选择题选项排版规则

通过统计4个选项的文字总长度，自动选择排版方式。
所有选项排版均使用模板"选项"样式中的制表位位置对齐，
而非 Word 默认制表位（默认值过小会导致选项间距不均匀）。

模板制表位位置（来自 dotx 样式 ID=13 "选项"）：
- 四选项一行：0.46, 4.54, 8.98, 13.43 cm
- 两选项一行：0.46, 8.98 cm

- **规则1（短选项）**：4个选项一行，Tab分隔
  - 条件：总长度 < 版心宽度60%
  - 制表位：4.54, 8.98, 13.43 cm
  - 示例：`A. ①③[TAB]B. ②④[TAB]C. ①④[TAB]D. ②③`

- **规则2（中等选项）**：AB一行，CD一行，Tab分隔
  - 条件：总长度 < 版心宽度120%
  - 制表位：8.98 cm
  - 示例：`A. 雄厚的经济基础[TAB]B. 发达的科学技术`

- **规则3（长选项）**：每个选项独占一行
  - 条件：总长度 >= 版心宽度120%
  - 示例：`A. 破坏生态景观协调性...`

- **规则4（①②③④子选项）**：先列子选项，再列ABCD
  - 子选项按内容长度自动分行
  - ABCD按规则1-3排版

- **规则5（图片选项）**：2x2排列，等比缩放
  - 条件：选项中包含 `{{IMAGE:...}}` 占位符
  - 布局：AB第一行，CD第二行，使用制表位对齐
  - 所有图片统一缩放至相同宽度（版心宽度40%，约6.9cm）
  - 确保视觉一致性

### 制表位与字体处理

- **制表位**：使用 `set_tab_stops()` 函数在段落上设置显式制表位，
  位置取自模板"选项"样式定义，确保选项间距与模板一致。
- **字体清除**：使用 `clear_run_fonts()` 清除段落中所有 run 的字体覆盖
  （`w:rFonts`、`w:sz`、`w:szCs`），让样式统一控制字体，
  避免原文档残留的字体设置干扰排版效果。

### 图片处理

- 材料图片：单独成段，居中，原始尺寸
- 选项图片：内嵌在选项文字位置
- 图片占位符格式：`{{IMAGE:filename.png}}`

### 表格处理

- 样式：Table Grid（样式11）
- 表头行：黑体、加粗、居中、英文/数字 Times New Roman
- 内容行：宋体、单倍行距、居中、英文/数字 Times New Roman
- 跨页时表头行自动重复
- **表格宽度**：默认适应版心宽度（17.2cm）
- **表格角色**：根据打标 JSON 中的 `role` 字段（`material`/`question`）
  区分材料表格与题目表格，两者表头均为黑体，差异在于排版上下文

### 填空题空位处理

- 自动检测题干和子问题中的连续下划线（3个及以上）
- 统一替换为标准长度（6个下划线 `______`）
- 在质检报告中统计填空空位总数

### 质检报告

排版完成后自动生成 `quality_report.html`（HTML 格式），包含以下内容：

- **试卷结构统计**：分区数、题组数、总题数、选择题/非选择题数量
- **排版规则使用统计**：各选项排版规则的使用次数
- **媒体资源统计**：插入图片数、插入表格数、填空空位数
- **缺失图片清单**：未能找到的图片文件列表
- **警告信息**：排版过程中的异常情况
- **质检结论**：通过/不通过的总览，带可视化状态徽章

## 脚本说明

| 脚本 | 用途 |
|------|------|
| `scripts/format_docx.py` | 主排版脚本，读取JSON+模板，输出排版docx |
| `assets/template.dotx` | 排版模板文件 |

### 脚本依赖

- python-docx（已验证版本 1.2.0）
- lxml（已验证版本 6.0.4）
- Python 3.8+

## 脚本使用约束（强制）

**AI必须严格遵守以下约束**：

1. **禁止自行编写脚本**：AI不得自己书写任何Python脚本或其他代码脚本，也不得用Write工具创建新的脚本文件。
2. **只能使用项目已有脚本**：AI只能通过RunCommand工具调用本skill目录下已有的脚本：
   - `scripts/format_docx.py`（排版脚本）
3. **功能不足时的处理**：如遇脚本功能不足，应向用户说明情况，**绝不自行编写替代脚本**。

## 注意事项

1. **模板文件**：必须使用配套的 template.dotx 模板，它包含了21种预定义样式。
   如果模板缺失或样式不完整，排版会失败。

2. **dotx 加载**：python-docx 默认不支持直接打开 .dotx 文件，
   脚本会先将 dotx 复制为临时 docx 文件再加载。

3. **科目名称**：两字科目加空格，统一为"地  理"。

4. **非选择题标题**：使用 Normal 样式（不是样式17），格式为
   "17. 阅读图文材料，完成下列要求。"

5. **图片路径**：图片文件从 images/ 目录读取，路径相对于 JSON 文件。

- **下游**：本 skill 输出的 formatted.docx 为最终交付物，供教师直接使用
