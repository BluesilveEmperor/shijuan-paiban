# 图片占位符插入规则

## 一、占位符格式规范

### 1.1 标准格式

**格式**：
```
【图片：<filename> - <description>】
```

**组成部分**：
- 中文方括号：【】
- 中文冒号：：
- filename：图片文件名（如img_001.png）
- 短横线分隔符：-
- description：图片描述（不超过30字）

**示例**：
```
【图片：img_001.png - 世界地图，显示洋流分布】
【图片：img_002.png - 人口变化折线图】
【图片：img_003.png - 水循环示意图】
```

---

### 1.2 待确认格式

当图片位置无法确定时，使用待确认格式：

**格式**：
```
【图片待确认：<filename> - <description>】
```

**示例**：
```
【图片待确认：img_010.png - 景观图，内容不明】
```

---

## 二、不同用途图片的插入位置规则

### 2.1 材料图（material）插入规则

**位置判断**：
- 查找"阅读图文材料"、"读图回答"、"据图回答"等引导语
- 在引导语所在段落**之前**插入占位符（另起一行）
- 如果材料段落没有引导语，在材料文字**开头**插入

**插入方式**：
- `new_paragraph`：另起新段落插入
- 占位符独立成段

**示例**：
```
阅读图文材料，完成下列要求。
【图片：img_001.png - 世界地图，显示洋流分布】
洋流对海洋生物的影响主要体现在...
```

---

### 2.2 选项图（option）插入规则

**位置判断**：
- 查找选项段落（A. B. C. D.格式）
- 在选项文字**末尾**插入占位符
- 如果选项本身是图片，替换选项文字为占位符

**插入方式**：
- `inline`：嵌入到选项文字中
- 不另起新段落

**示例**：
```
A. ①③【图片：img_002.png - 方位示意图】
B. ②④
C. ①④
D. ②③
```

---

### 2.3 题目图（question）插入规则

**位置判断**：
- 查找题干段落（题号开头）
- 在题干文字**末尾**或**开头**插入占位符
- 根据图片与题干内容的关联判断位置

**插入方式**：
- `inline`：嵌入到题干文字中
- 或`new_paragraph`：另起新段落（视具体情况）

**示例**：
```
1. 图中洋流对海洋生物的影响主要体现在【图片：img_001.png - 洋流分布图】哪些方面？
```

---

### 2.4 无法确定位置（unknown）处理

**位置判断**：
- 无法确定图片用途或位置
- 插入到文档**末尾**

**插入方式**：
- 使用待确认格式
- 在日志中标记"待人工确认"

**示例**：
```
【图片待确认：img_010.png - 景观图，内容不明】
```

---

## 三、特殊情况处理

### 3.1 多图插入

当同一位置需要插入多张图片时：

**处理方式**：
- 每张图片单独插入占位符
- 占位符之间空一行

**示例**：
```
阅读图文材料，完成下列要求。
【图片：img_001.png - 世界地图】

【图片：img_002.png - 区域放大图】
```

---

### 3.2 图片与表格组合

当图片与表格同时出现时：

**处理方式**：
- 图片占位符在前，表格占位符在后
- 或根据原文顺序排列

**示例**：
```
【图片：img_001.png - 地形图】
【表格：table_001 - 人口统计数据】
```

---

### 3.3 选择题选项全部为图片

当选择题四个选项都是图片时：

**处理方式**：
- 每个选项嵌入对应的图片占位符
- 保持选项格式

**示例**：
```
A. 【图片：img_a.png - 方案示意图】
B. 【图片：img_b.png - 方案示意图】
C. 【图片：img_c.png - 方案示意图】
D. 【图片：img_d.png - 方案示意图】
```

---

### 3.4 综合题子问题包含图片

当综合题的子问题包含图片时：

**处理方式**：
- 图片占位符嵌入到子问题文字中
- 或另起新段落

**示例**：
```
（1）图中①表示的地理现象是【图片：img_001.png - 示意图】...
```

---

## 四、插入位置记录格式

每张图片插入位置记录格式：

```json
{
  "filename": "img_001.png",
  "insert_position": {
    "paragraph_index": 15,
    "insert_type": "new_paragraph",
    "context": "阅读图文材料，完成下列要求。",
    "position_description": "材料引导语段落之前"
  },
  "placeholder": "【图片：img_001.png - 世界地图，显示洋流分布】",
  "status": "success"
}
```

**字段说明**：
- `paragraph_index`：插入位置的段落索引
- `insert_type`：插入方式（new_paragraph/inline）
- `context`：插入位置附近的上下文文字
- `position_description`：位置描述说明
- `status`：插入状态（success/pending/manual_confirm）

---

## 五、注意事项

1. **不破坏文档结构**：
   - 保持原有段落顺序
   - 不删除原有文字内容
   - 不合并或拆分段落

2. **占位符格式统一**：
   - 使用中文方括号【】
   - 使用中文冒号：
   - 使用短横线分隔

3. **描述简洁准确**：
   - 从images_analysis.json中获取描述
   - 不超过30字
   - 准确反映图片内容

4. **待确认图片标记**：
   - 无法确定位置的图片必须标记"待确认"
   - 在日志中记录原因
