### 2.1 三级答题空间模式

**当前**：`onepage` / `space` 两种极端

**改进后**：

| 模式 | 学生版 | 教师版 | 适用场景 |
|------|--------|--------|---------|
| `compact` | `itemsep=0.3em` + 无线 | 每题下方 2em | 自学、参考 |
| `normal`（默认） | `itemsep=1.0em` + 每题后 3em 答题框 | 每题下方 6em | 课后作业 |
| `exam` | `itemsep=1.5em` + 每题后 5em 答题框 | 每题独占一页 | 课堂测试 |

### 2.2 题目内容感知的空间分配

**当前**：所有题目 `itemsep` 固定

**改进**：根据题目特征动态计算

```
空间权重 = 1.0（基础）
         + 小问数 × 0.4
         + 含图 × 0.6
         + 文本长度 > 200字 × 0.3
         + 含"证明" × 0.5
```

**示例**：
- 第15题（13分，1小问，无图）→ 权重 1.4
- 第18题（17分，2小问，含图）→ 权重 2.4
- 第19题（17分，3小问，含图）→ 权重 2.8

**实施位置**：`gen_paper.py` 中增加 `analyze_question_weight()` 函数

---

### 2.3 学生版答题区域

**当前**：学生版只有题目，无答题标记

**改进**：纯留白，无线条无边框，保持试卷整洁美观

```latex
% ── 答题空间命令（纯留白，无任何线条）──
% compact：最小间距，适合自学
\newcommand{\answerc}{%
  \par\vspace{1.5em}%
}

% normal：适中间距，适合课后作业
\newcommand{\answern}{%
  \par\vspace{3em}%
}

% exam：较大间距，适合课堂测试
\newcommand{\answere}{%
  \par\vspace{5em}%
}
```

**设计原则**：
- **禁止**使用 `\rule`、`tcolorbox`、`fbox` 等任何带线条的命令
- **禁止**使用虚线、点线、角标等任何视觉标记
- 仅通过 `\vspace` 控制留白量，让答题空间"隐形存在"
- 留白量由模式决定：compact=1.5em / normal=3em / exam=5em

**实施位置**：
- `templates/gaokao-template.tex` 导言区
- SKILL.md 步骤 4 增加"答题空间插入规则"

### 2.4 `itemsep` 自动计算

**当前**：手动试错

**改进**：给出经验公式

```
目标：4页试卷，5道解答题，均匀分布

可用空间 = 页高 - 页眉页脚 - 选择题/填空题占用 - 解答题题目本身占用
itemsep = 可用空间 / 解答题数

经验值：
- 4页5题 → itemsep ≈ 1.5 ~ 2.0cm
- 4页3题 → itemsep ≈ 2.0 ~ 2.5cm
- 6页5题 → itemsep ≈ 2.5 ~ 3.0cm
```

**实施位置**：SKILL.md 步骤 4 增加"itemsep 计算公式"

### 2.5 编译后页数自适应

**当前**：编译 → 看结果 → 手动改 → 再编译

**改进**：编译后自动检测，超页时自动压缩

```python
def auto_adjust(tex_path, target_pages=4, max_rounds=3):
    for _ in range(max_rounds):
        pages = compile_and_count(tex_path)
        if pages == target_pages:
            return True
        elif pages > target_pages:
            reduce_spacing(tex_path)  # 减小 itemsep 或 linespread
        else:
            increase_spacing(tex_path)
    return False
```

**实施位置**：`scripts/auto_adjust.py` 新脚本

### 2.6 `tasks` 列数自动判断

**当前**：固定 4 列或 2 列

**改进**：根据选项内容自动选择

```python
def auto_tasks_cols(options):
    """自动判断 tasks 列数"""
    avg_len = sum(len(opt) for opt in options) / len(options)
    has_image = any(opt.startswith('\\includegraphics') for opt in options)
    has_formula = any('$' in opt for opt in options)
    
    if has_image:
        return 4 if avg_len < 50 else 2
    elif avg_len > 20 or has_formula:
        return 2
    else:
        return 4
```

**实施位置**：SKILL.md 步骤 4 增加"tasks 列数自动判断规则"
