## 1. 技能定位

**一句话原则**：用户只提供试卷文件路径（DOCX 或 PDF）+ 模板路径，agent 全自动完成
提取 → 转换 → 编译 → 验证，用户全程不需要知道任何脚本路径。

**输入格式自动识别（入口分流）**：

| 输入类型 | 提取方案 | 依赖 |
|---------|---------|------|
| `.docx` | pandoc 提取文本 + 解包取图片（原方案） | pandoc、docx skill、Pillow |
| `.pdf`  | MinerU SDK 提取 Markdown + 图片 | mineru-open-sdk、MinerU API Token、math-reference-read skill |

## 2. 标准工作流（7 步）

### 第 1 步：读取文件 → 看结构

**DOCX 通道**：

```bash
pandoc "<docx路径>" -t markdown --wrap=none --track-changes=all
```

快速浏览输出，识别：标题、题型（单选/多选/填空/解答）、题目编号、选项、
图片标记（`![...](media/imageN.png)` 或 `.wmf`）。

**PDF 通道**：

1. 先检查 `~/.mineru/config.yaml` 是否有有效 `token`——没有则友好引导用户配置
   （`pip install mineru-open-sdk` → 创建配置文件写入 token → 到
   https://mineru.net/apiManage/token 注册获取），不直接报错退出。
2. 用 math-reference-read 的配套脚本提取：

```bash
python "$MATH_SKILL_DIR/scripts/math_pdf_extract.py" "<pdf路径>" \
  --output-dir ./math-output --language en
```

3. 读取输出目录的 `.md` 确认提取质量（MinerU 默认开启公式识别，公式已是 LaTeX 格式）。

### 第 2 步：提取图片

- **DOCX 通道**：解包取图片（docx skill 的 unpack 脚本）；WMF 公式图批量转 PNG（600 DPI）。
- **PDF 通道**：MinerU 自动提取图片到输出目录；检查图片在 `math-output/` 直接下还是
  `math-output/<文件名>/` 子目录里，必要时移动到 docx 所在目录。

**图片目录命名规则（用户可覆盖）**：

| 文档类型 | 图片目录 |
|---------|---------|
| 答案文档（文件名含"答案"） | `Images-<文件名>`（如 `新一卷数学-答案.docx` → `Images-答案`） |
| 试题文档 | 固定 `media` |
| PDF 输入 | `Images-<PDF文件名>`（MinerU 自动保存到输出目录） |

后续 LaTeX 的 `\graphicspath` 统一指向这个 `{图片目录}`。

### 第 3 步：读模板 → 知能力

两个模板内嵌在 SKILL.md 末尾的「嵌入式模板库」，无需外部文件：

| 模板 | 用途 |
|-----|------|
| `gaokao-template.tex` | 试题模板（学生版/教师版） |
| `gaokao-answer-template.tex` | 答案模板 |

**自动选择规则**：

- 文件名含"答案" → 答案模板
- 用户指定 gaokao-template 或明显是高考数学试卷 → 试题模板
- 答案文件路径无"答案"但用户点名 → 答案模板

**答案文档的"三段式试题匹配"**（找同目录对应试题 `.tex`，保证答案卷题干与试题卷完全一致）：

1. **精确剥离**：依次去掉 `-答案` / `_答案` / `答案` / `答案-` / `答案_` 后缀拼 `.tex`
2. **公共前缀匹配**：扫描同目录 `.tex`（排除 `*教师版*`、`gaokao*`、`*template*`），
   取最长公共前缀 ≥ 3 字符的文件
3. **回退**：都没找到 → 直接用输入文件的题目文本

**读模板时重点确认**：选择题环境（tasks?）、大题编号（examenum?）、是否已加载
graphicx/wrapfig（没有则补 `\usepackage{wrapfig}`）、自定义命令（`\blank` `\mycircled`
`\Parallel`）、当前 linespread 设置。

### 第 4 步：写 LaTeX → 逐题转换

**铁律**：保留模板完整导言区（`\documentclass` 到 `\begin{document}`），只替换
`\begin{document}` 到 `\end{document}` 之间的正文。

**数学公式规范**：

- 行内 `$...$`，行间 `\[...\]`
- 分数 `\frac{}{}`，太长用 `\dfrac{}{}`（Overfull 时换回 `\frac`）
- `\sin` `\cos` `\tan`，`\ln` `\lg`；分段函数 `\begin{cases}`
- 集合 `\{` `\}` 转义、`\mid` 表示"使得"；向量 `\vec{a}` / `\mathbf{a}`
- `\pi`；`\mathrm{e}` 自然底数、`\mathrm{i}` 虚数单位（答案模板已简写为 `\me` / `\mi`）

**题型编号约定（新高考 I 卷）**：

| 题型 | 环境 |
|-----|------|
| 选择题 1-8 | `\begin{enumerate}[itemsep=0.3em]` |
| 多选题 9-12 | `\begin{enumerate}[start=9]` |
| 填空题 13-16 | `\begin{enumerate}[start=12]` |
| 解答题 17-22 | `\begin{examenum}[start=17, itemsep=2.5cm]` |

选项 → tasks 环境（简短 4 列，内容长 2 列）；填空空位 → `\blank`；大题多问 → examenum 嵌套。

**图片插入三档**（所有图片宽度不得超过 `0.35\textwidth`，显示在题目内容右侧）：

1. 小装饰图 → `\includegraphics[height=0.6em]`（行内）
2. 几何示意图（列表环境外）→ `wrapfigure` 右侧环绕，宽 `0.35\textwidth`
3. 几何示意图（列表环境内，wrapfigure 失效）→ `minipage` 左右并排：
   左 `0.62\textwidth` 放题目 + 小问，右 `0.30\textwidth` 放图片 + `\captionof{figure}`
4. TikZ 图 → `\resizebox{0.35\textwidth}{!}{...}` 控制宽度

**答案文档特例**：

- `\graphicspath{{images/}}` 必须替换为 `\graphicspath{{{图片目录}/}}`
- 选项图用 `\eqimg[0.15]{imageN.png}`（DOCX 通道）；PDF 通道优先直接用 LaTeX 公式
- 每题结构固定：题目文本 → `\daan{答案}` → `\jieti`（解析）→ `\xijie`（详解）
- 解答题多问用 `\xiaoI` / `\xiaoII` 分别标注【小问 1/2 详解】
- 表格 → 标准 `tabular` + `booktabs` 三线表 + `\captionof{table}`
- 答案文档不需要生成教师版，也不需要 `itemsep` 间距

**页数控制（硬约束）**：学生版严格匹配试卷标注的"本试卷共X页"；超页时在导言区加
`\linespread{1.05}\selectfont`（视觉几乎无感，能省半页到一页）。

### 第 5 步：生成教师版（仅试题文档，答案文档跳过）

- 前面三个大题（一～三）连续排版不分页
- 解答题每题单独分页：Q17 紧跟"四、解答题"标题，Q18~Q22 各起新页
- 页数紧张时 Q22 可不分页（紧接 Q21 后，Q21 通常已独占一页）

实现：Python 脚本（`gen_teacher.py`）按 examenum 外层 `\item` 计数插入 `\newpage`，
并从 `[start=17, itemsep=2.5cm]` 中移除 `itemsep`（分页已替代间隙作用）。

> ⚠️ **陷阱**：Python 里匹配 LaTeX 命令必须用 raw string（`r"\begin"`），否则
> `"\\begin"` 里的 `\b` 会被解析成退格符 0x08 导致匹配失败。

### 第 6 步：编译 → 验证

试题文档（学生版 + 教师版各编译两次，XeLaTeX 需两遍跑完交叉引用）：

```bash
xelatex -interaction=nonstopmode "<输出文件名>.tex"
xelatex -interaction=nonstopmode "<输出文件名>.tex"
grep -E "Overfull|Error" "<输出文件名>.log" | grep -v infwarerr
```

答案文档只编译一个版本。**验证要点**：

- 学生版/答案版页数与试卷标注一致（如"本试卷共4页"）
- 教师版 ≤ 7 页；解答题编号正确
- 答案文档 `\daan` / `\jieti` / `\xijie` 结构显示正确；图片全部正常显示

### 第 7 步：清理

- **删除**：临时目录、`gen_teacher.py`、`.aux` / `.log` / `.out` 辅助文件
- **保留**：
  - 试题文档 → 学生版 `.tex` + 教师版 `.tex` + 两个 `.pdf` + 图片
  - 答案文档 → 一个 `.tex` + 一个 `.pdf` + `{图片目录}/`（含公式 PNG）

## 3. 试题模板排版细节（gaokao-template.tex）

### 页面与字号

- `\documentclass[12pt, a4paper, oneside]{ctexart}`
- 边距：`geometry` `margin=2.5cm`，`footskip=1cm`（2606 卷紧凑布局）
- 行距默认单倍；预留 `\linespread{1.5}` 选项但注释（1.5 倍会明显增页）

### 字体

数学字体 `newtxmath`（Times 风格，兼容 pdflatex + ctex）为默认；
可注释切换 `stix2`（更现代）+ `upgreek` 直立希腊字母。

### 页眉页脚

- `fancyhdr` + `lastpage`（动态总页数）
- 页脚居中：`数学试题第X页（共Y页）`（`\fancyfoot[C]`）
- 页眉线 / 页脚线均 `0pt`（无）

### 核心宏包

`amsmath` / `amsthm` / `amssymb`、`hyperref`（colorlinks，citecolor=blue，
linkcolor=black）、`graphicx`、`adjustbox`、`diagbox`（斜线表头）、`makecell`
（单元格换行）、`caption`、`float`（[H] 强制定位）、`tikz`（绘图）。

### 选择题选项：tasks 环境配置

```latex
\settasks{
    label        = \Alph*.,
    label-width  = 1.8em,
    item-indent  = 2.4em,
    label-offset = 0.5em,
    column-sep   = 2em,
    before-skip  = 0pt,
    after-skip   = 0pt
}
```

列数：`\begin{tasks}(4)` 四列（简短选项）；内容长时改 `(2)` 两列。

### 大题编号：examenum 环境（enumitem 三级嵌套）

```latex
\newlist{examenum}{enumerate}{3}
\setlist[examenum,1]{label=\arabic*., leftmargin=2em, itemsep=0.3em, parsep=0em}
\setlist[examenum,2]{label=(\arabic*), leftmargin=1.5em, itemsep=0.1em, parsep=0em}
\setlist[examenum,3]{label=(\roman*), leftmargin=1.5em, itemsep=0.1em, parsep=0em}
```

| 层级 | 编号样式 | 缩进 | 间距 |
|-----|---------|------|------|
| 一级（大题） | 阿拉伯数字 `1.` | 2em | itemsep 0.3em |
| 二级（小问） | 括号数字 `(1)` | 1.5em | itemsep 0.1em |
| 三级（嵌套） | 罗马数字 `(i)` | 1.5em | itemsep 0.1em |

### 自定义命令

```latex
% 圈号数字（条件编号 ①②③，TikZ 绘制）
\newcommand{\mycircled}[1]{%
  \tikz[baseline=(char.base),outer sep=0pt]{%
    \node[draw,circle,inner sep=0.5pt,minimum size=1.4em,
          line width=0.4pt,font=\zihao{-5}] (char) {#1};%
  }%
}
% 旋转平行符号（立体几何线线平行）
\newcommand{\Parallel}{\raisebox{0.1ex}{\rotatebox[origin=c]{-20}{$\parallel$}}}
% 密级星号
\newcommand{\bigstarraised}{\raisebox{0.2ex}{$\bigstar$}}
% 下划线填空
\newcommand{\blank}{\underline{\hspace{2cm}}}
% 大标题辅助命令
\newcommand{\subjecttitle}[1]{{\fontsize{24pt}{22pt}\selectfont\centering\textbf{#1}\par}}
\newcommand{\subtitle}[1]{{\fontsize{16pt}{16pt}\selectfont\centering #1\par}}
```

### 标题区两种方案

- **方案 A（紧凑，2606 风格，默认）**：单行合并
  `202X年全国统一高考数学试卷\\新高考I卷`，`\LARGE` 加粗居中——省页数
- **方案 B（展开，2506 风格）**：年份与科目分两行（`\subtitle` + `\subjecttitle`）——占位多

### 题型结构与编号

| 大题 | 题量与分值 | 环境 |
|-----|-----------|------|
| 一、选择题（单选） | 8 题 × 5 分 = 40 分 | `\begin{enumerate}[itemsep=0.3em]` + tasks(4) |
| 二、选择题（多选） | 3 题 × 6 分 = 18 分 | `\begin{enumerate}[start=9]` + tasks(2) |
| 三、填空题 | 3 题 × 5 分 = 15 分 | `\begin{enumerate}[start=12]` + `\blank` |
| 四、解答题 | 5 题共 77 分 | `\begin{examenum}[start=17, itemsep=2.5cm]` |

每题分值标注格式：`\item （13分）...` / `\item （15分）...` 紧跟题干。

### 表格风格

`tabular` 带竖线 + `diagbox` 斜线表头（`\diagbox{组别}{检查结果}`）+ `makecell`
单元格内换行 + `float` [H] 强制定位——列联表 / 统计表专用。

### 配图

立体几何图直接 `tikzpicture` 画坐标点 + 虚线实线，配 `\captionof{figure}{图注}`。

## 4. 答案模板排版细节（gaokao-answer-template.tex）

### 页面布局

- `\documentclass[12pt, a4paper]{ctexart}`
- 边距不对称：`top=2cm, bottom=2cm, left=2.5cm, right=2.5cm`（上下更窄）
- `\onehalfspacing` 固定 1.5 倍行距（答案卷信息量大，行距拉开便于阅读）

### 页眉页脚

- 页眉居中：`202X年普通高等学校招生全国统一考试·数学 参考答案`（small）
- 页脚居中：纯页码 `\thepage`
- 页眉线 `0.4pt`（与试题卷的无线条形成区分）

### 图片路径

`\graphicspath{{images/}}` —— 转换时必须替换为推导出的 `{图片目录}/`
（如 `Images-答案`），否则 `\eqimg` 和 `\includegraphics` 全部找不到图。

### 命令体系（答案卷核心排版语义）

```latex
% 【答案】红色加粗
\newcommand{\daan}[1]{{\color{red}\textbf{【答案】#1}}}
% 【解析】灰色前缀，正文用楷体
\newcommand{\jieti}{\par{\color{gray!60!black}\textbf{【解析】}}}
% 【详解】蓝色前缀
\newcommand{\xijie}{\par{\color{blue!60!black}\textbf{【详解】}}}
% 【小问 1/2 详解】蓝色前缀
\newcommand{\xiaoI}{\par{\color{blue!60!black}\textbf{【小问 1 详解】}}}
\newcommand{\xiaoII}{\par{\color{blue!60!black}\textbf{【小问 2 详解】}}}
% 插入公式图片（WMF 转 PNG），默认宽 0.5\textwidth
\newcommand{\eqimg}[2][0.5]{%
  \includegraphics[width=#1\textwidth,keepaspectratio]{#2}%
}
% 虚数单位 / 自然底数简写
\newcommand{\mi}{\mathrm{i}}
\newcommand{\me}{\mathrm{e}}
```

| 命令 | 样式 | 用途 |
|-----|------|------|
| `\daan{...}` | 红色加粗【答案】 | 答案 |
| `\jieti` | 灰色前缀【解析】（正文楷体） | 解析 |
| `\xijie` | 蓝色前缀【详解】 | 详解 |
| `\xiaoI` / `\xiaoII` | 蓝色前缀 | 小问 1/2 详解 |
| `\eqimg[宽]{图}` | 图片，默认 0.5\textwidth | 公式图片（选项图常用 0.15） |
| `\mi` / `\me` | 直立体 | 虚数单位 / 自然底数 |

### 标题区（密级风格）

`绝密★启用前 试卷类型：A`（large 加粗）→ 考试名称（Large）→ `数 学`（huge）
→ `参考答案`（large）→ `\hrule` 横线收尾。

### 题型结构与命令搭配

| 大题 | 环境 | 命令链 |
|-----|------|--------|
| 一、选择题 | `\section*{一、选择题}` + `enumerate` | `\daan` → `\jieti` → `\xijie` |
| 二、选择题（多选） | `enumerate[resume]` | 同上，选项 flushleft 平铺 |
| 三、填空题 | `enumerate[resume]` | 下划线填空 + `\daan` |
| 四、解答题 | `enumerate[resume]` + 嵌套小问 | `\daan{(1)…(2)}` → `\jieti` → `\xiaoI` → `\xiaoII` |

注意：答案模板题号全走 `enumerate` 体系并 `[resume]` 接续编号，不用 tasks
（选项多为图片，用 `flushleft` + `\eqimg` 平铺）。

### 选项排版双通道差异

| 输入 | 选项处理 |
|-----|---------|
| DOCX | 选项是 WMF 公式图 → `\eqimg[0.15]{imageN.png}` 逐个插入 |
| PDF | MinerU 已识别为 LaTeX 公式 → 优先直接写公式，图片才用 `\eqimg` |

## 5. 通用排版约定

### 图片插入三档（两模板共用）

1. 小装饰图 → `\includegraphics[height=0.6em]`（行内）
2. 几何示意图（列表环境外）→ `wrapfigure` 右侧环绕，宽 ≤ `0.35\textwidth`
3. 几何示意图（列表环境内，wrapfigure 失效）→ `minipage` 左右并排：
   左 `0.62\textwidth` 放题目 / 小问，右 `0.30\textwidth` 放图片 + `\captionof{figure}`

### 数学公式规范

行内 `$...$` / 行间 `\[...\]`；分数 `\frac`，超长用 `\dfrac`（Overfull 时换回）；
`\sin` `\cos` `\tan` `\ln` `\lg`；`cases` 分段函数；集合 `\{` `\}` 转义、
`\mid` 表"使得"；向量 `\vec` / `\mathbf`；`\pi`；`\mathrm{e}` / `\mathrm{i}`
（答案模板已简写为 `\me` / `\mi`）。

### 页数控制（反复强调的硬约束）

- **学生版**：必须严格匹配试卷标注的"本试卷共X页"
- **超页手段**：导言区加 `\linespread{1.05}\selectfont`（视觉几乎无感，省半页到一页）
- **教师版**：不受标注页数约束，控制在 7 页内
- **教师版**：移除 `itemsep=2.5cm`（分页已替代间隙作用）

### 一致性原则

转换时保留模板完整导言区，只替换正文；标题格式、注意事项文字、各题型标题、
分值标注格式全部照抄模板，不自由发挥。

## 6. 常见问题速查

| 症状 | 修复 |
|------|------|
| Overfull `\hbox` | 选项改 2 列；`\dfrac` 改 `\frac`；缩短公式 |
| 图片错位 / 消失 | 列表环境内改用 `minipage` 方案 |
| 页数超限 | `\linespread{1.05}` 压缩行距 |
| MinerU 解析失败（PDF） | 检查 Token；文件 ≤ 200MB / 600 页；扫描件加 `--ocr` |
| UnicodeEncodeError（Windows） | 加 `PYTHONIOENCODING=utf-8` 前缀 |
| 中文不显示 | 确认模板用 `ctexart` |

## 附：整条链路一句话总结

识别格式 → 提取（pandoc / MinerU）→ 取图（解包 / WMF 转 PNG）→ 选模板（含答案
三段式匹配）→ 逐题转 LaTeX（守导言区、守编号、守图片环绕）→ 分版本（学生 / 教师）
编译验证（XeLaTeX × 2 + Overfull 检查 + 页数核对）→ 清理保留产物。

试题卷风格 = 12pt + 2.5cm 边距 + tasks 选项 + examenum 三级大题 + 页脚"第X页（共Y页）"；
答案卷风格 = 上下 2cm 边距 + 1.5 倍行距 + 红【答案】灰【解析】蓝【详解】命令体系 +
`\eqimg` 公式图。两者共用同一套数学公式规范与图片环绕规则，页数是贯穿始终的硬约束。
