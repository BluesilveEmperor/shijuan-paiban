# 答题卡生成细节

> SKILL.md 的「步骤 5-B」只给命令；参数语义、自动识别逻辑、附图规则与排障在此。

一条命令：

```bash
python scripts/render/gen_answer_sheet.py "<试卷.tex>"
```

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--layout` | `a4` | `a4` / `a3` / `both`（a3 每张纸并排两个 A4 版面，对折成册） |
| `--pages` | 自动 | 强制版面数（a4=页数，a3=张数） |
| `--block` | `2` | 每面最多几道解答题 |
| `--percol` | `4` | 选择题每列题数 |
| `--title` / `--subject` | 自动 | 覆盖卷头文字 |
| `--bw` | 关 | 黑白版（不印彩色框线） |
| `--no-compile` | 关 | 只出 `.tex` 不编译 |
| `--no-figs` | 关 | 不附带解答题的图/三线表，只出纯答题区 |
| `--print-spec` | — | 只打印解析结果，用于核对题量与附图 |
| `--suffix` | `答题卡` | 输出文件名后缀（同名手工版已存在时换个后缀即可） |
| `--force` | 关 | 允许覆盖非本脚本生成的文件（默认拒绝） |
| `--single/--multi/--blanks/--solves` | — | 解析失败时手工兜底 |

## 两道安全防护（默认开启）

- **拒绝非试卷输入**：文件名含 `答案` / `教师版` / `答题卡` / `解析` / `详解` 时直接报错退出（退出码 4）
  ——答题卡只能从试卷解析。
- **不覆盖手工版**：目标 `.tex` 已存在且开头没有本脚本的生成标记时，跳过并提示（退出码 5），
  原文件分毫不动。确认要替换加 `--force`，或换个 `--suffix`。

## 题量自动识别（读试卷 `.tex` 正文，不依赖文件名）

| 项 | 识别方式 |
|----|---------|
| 单选 / 多选 | 扫 `\section*{一、…}`、`\noindent\textbf{二、…}` 等小节标题，按「单选/多选/多项选择/多项符合」分类，再数该小节内**顶层** `\item`（自动跳过嵌套 `examenum`） |
| 填空 | 同上，「填空题」小节 |
| 解答题 | 数顶层 `\item`，并从 `（本题满分 13 分）` / `（本小题满分 13 分）` / `（13分）` / `(13 分)` 中取分值 |
| 卷头 | 收集 `\textbf{…}`（容许一层嵌套，如 `\textbf{\LARGE{…}}`）与 `\subtitle{}` / `\subjecttitle{}` / `\title{}`，剔除「绝密★启用前」「试卷类型」「本试卷共…」「一、选择题…」等干扰项，再按「含考试/高考/联考/期末…」加权取最高分；`\\` 换行转全角空格（普通空格会被 ctex 吞掉） |

## 版面数自动推算

复刻 `answersheet.sty` 的分页算法，取最小可行值：

1. 先找「可行」的最小版面数：**不能有空版面**（多出来的版面会变成一整片空白答题框），
   且每面解答题数 ≤ `block`；
2. 再看每分能摊到多少答题高度：`可用高度 / 总分 ≥ 1.05cm` 才认可，否则在 +1～+3 版面内找一个达标的；
3. 实测：新高考 19 题 → 4 版面（与宏包预设一致）；22/23 题 → 4 版面（比宏包注释的 5 更紧凑，
   要更宽松就 `--pages 5`）。

## 解答题附图 / 三线表（默认开启）

立体几何的题图、统计题的表格会自动搬到答题卡对应题目的作答区，学生直接在图上画辅助线、
在表里填数——不用另外打印试题。

| 内容 | 判定 | 放置方式 |
|------|------|---------|
| 单个 `tikzpicture` / `\includegraphics` | 角图 | 作答区右上角，容器宽 6cm |
| `center` 块里并排多图、含 `minipage` | 通栏 | 作答区顶部居中，容器宽 15cm |
| `tabular` / `tabularx` / `longtable`（含三线表） | 通栏 | 同上 |

- **提取粒度**：优先整块取 `center` 环境（保留「图(1) 图(2) 并排」「图 + 图注」的原版式），
  再捡散落的 `tikzpicture` / `\includegraphics` / `tabular`；同题多个图表会合并成一次调用
  （宏包按题号存储，重复调用会互相覆盖）。
- **依赖自动跟随**：原卷导言区里 `diagbox` / `booktabs` / `multirow` / `makecell` 等图表宏包、
  以及 `\usetikzlibrary{…}`、`\graphicspath{…}` 会一并带过来（`geometry` / `fancyhdr` / `hyperref`
  这类版式宏包**绝不**搬）。所以 `\diagbox` 斜线表头也能正常排。
- **放不下就降密度**：图是硬内容，压过分隔线会盖住下一题。脚本先估图高，超过答题框 85%
  就自动改成「每题独占一面」（`block=1`），并打印 `[INFO]`；单面 24.5cm 仍放不下才 `[WARN]`
  让用户手工删减。**不在 TeX 里现场缩放**——量高度易错，缩出来的字号也不可控。
- **编译兜底**：带图版编译失败时（原卷图引用了答题卡里没有的宏/图片），自动退回无图版重编
  并打印错误摘要，保证答题卡本身一定能出。
- **不要图**：`--no-figs`。

## 排障

| 症状 | 做法 |
|------|------|
| 解答题写不开 | `--pages 5`（加版面） |
| 页面太空 / 太多页 | `--pages 3`，或 `--block 3` |
| 选择题挤成一坨 | `--percol 3`（每列 3 题） |
| 黑白印刷 | `--bw` |
| 某题图太大、自动变成每题一面 | 想要紧凑就 `--no-figs`，或先删原卷里多余的图 |
| 解析出的题量不对 | 先 `--print-spec` 核对，再用 `--single/--multi/--blanks/--solves` 覆盖 |

## 输出与模板

输出物（与试卷同目录）：

```
2611数学答题卡（A4）-<考试名>.tex / .pdf    A4，4 个版面（命名规范见 ARTIFACT-002）
2611数学答题卡（A3）-<考试名>.tex / .pdf    A3 横向，2 张纸（--layout a3/both 时）
answersheet.sty                宏包副本，供日后单独重编
```

**必须 xelatex 连编两次**（模板用 `remember picture` 定位，一次页码与坐标不准）。脚本已自动连编
两次并清理 `.aux/.log`。版式参数改动后若位置错乱：删掉同名 `.aux` 再连编两次。

模板本体：`templates/common/answer-sheet/answersheet.sty`（宏包）+ `answer_sheet.tex`
（骨架，含三档卷型预设注释）。换配色改 `--color`（任意 xcolor 颜色名，默认 `GKpink`）。

宏包侧的附图接口（手工建卡时用）：

```latex
\begin{document}
\gkFig{16}{\begin{tikzpicture}...\end{tikzpicture}}   % 右上角小图
\gkBlock{19}{\begin{tabular}{...}...\end{tabular}}   % 顶部通栏（宽表）
\gkMake
\end{document}
```
