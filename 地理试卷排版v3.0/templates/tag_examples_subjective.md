# 非选择题打标案例

> 供 `tag_structure` (Step2) 在处理**非选择题**时参考。
> **触发条件**：试卷包含非选择题分区（`section.type = "非选择题"`）。
> 包含：多段材料拆分、"材料一/二"标记处理、单问 label 规则、子问题含①②③序号拆分。

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **三段独立材料** | 每段讲不同方面，独立成段 → 拆为 3 个 `material` | 合并为1个材料 |
| **guide_sentence 为空** | 各材料末尾无"据此完成X题"等引导语句，`guide_sentence` 为 `""` | 硬造一个引导语 |
| **"阅读图文材料"** | 这是非选择题的标准引导语，归入 `stem`，不是材料 | 把它当成材料的一部分 |
| **题干含分数** | "（16分）" 保留在 `stem` 中 | 去掉分数信息 |
| **子问题含引用号** | 子问题(2)中包含弯引号""，必须保留原样 | 替换为直引号"" |

## 案例2：非选择题 — 含"材料一""材料二"标记

### 原文

```
17. 阅读图文材料，完成下列要求。（14分）

材料一：环渤海地区是我国经济增长的"第三极"，加强环渤海及京津冀地区经济协作，努力实现京津冀协同发展是重大国家战略。下图为京津冀都市地区城际铁路网规划示意图和京津冀产业特征及区域联系图。

【图片位置】

材料二：天津市武清区地处京津之间，是天津市唯一全域纳入首都通勤圈的行政区。武清区与北京市之间单日最高开行70趟列车，2.3万人通勤往返于两地之间。5年来，武清区引进北京市项目129个、总投资583.8亿元，为北京市产业链配套企业超260家。武清区实有人口从2022年末的113万人增长至目前的121.2万人，3年人口增量8.2万人，其中相当一部分新增人口来自北京市。更引人注目的是，新增人口中35岁以下青年占比超七成。武清区依托高铁站，发展"站产城"融合模式—以站带产、以产兴城、以城聚人。该区将目光聚焦在智能科技、生物医药为"双高引领"的产业方向上，这恰恰是北京市科创资源最密集、外溢需求最强的领域。

(1) 分析京津冀地区铁路线空间分布变化对城市发展带来的有利影响。（4分）
(2) 读京津冀产业特征及区域联系图，分析北京、天津随着产业与技术扩散，可以带来哪些益处？（4分）
```

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|

## 案例4：非选择题子问题含①②③序号

### 原文

```
(2) 马山县黑山羊销往粤港澳地区较多，主要是因为：
①马山县所在省区与粤港澳地区毗邻，运输距离短，运输成本低
②马山县发展较为滞后，当地黑山羊销售价格与粤港澳地区差异大，将黑山羊销往粤港澳地区______
③粤港澳地区人口众多______，______
```

```json
      "stem": "马山县所在省区与粤港澳地区毗邻，运输距离短，运输成本低"
    },
    {
      "id": "subq_006",
      "label": "(2)-②",
      "stem": "马山县发展较为滞后，当地黑山羊销售价格与粤港澳地区差异大，将黑山羊销往粤港澳地区______"
    },
    {
      "id": "subq_007",
      "label": "(2)-③",
      "stem": "粤港澳地区人口众多______，______"
    }
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **①②③拆分为独立子问题** | 每个序号对应一个 `subquestions` 条目 | 把整个段落作为一个子问题 |
| **label 格式** | 父标签+序号：`"(2)-①"`、`"(2)-②"` | `label` = "①"（丢失父级编号） |
| **stem 不含序号** | `stem` 不含①②③序号前缀 | `stem` = "①马山县所在省区..." |
| **填空空位** | `______` 保留在 `stem` 中 | 替换为统一格式或去掉 |

## 案例5：新题型 — 材料与子问题交错排列 + 非标准材料标题

### 原文

```
28. 阅读图文资料，完成下列要求。（13分）

【研学背景】
泉州某中学组织学生前往江西景德镇与福建德化开展"探寻千年瓷都，对话闽赣产业"主题研学活动。

【研学见闻一：德化的"白色世界"】
第一站来到德化。这里瓷土资源丰富，以日用瓷、西洋工艺瓷为主，数字化、智能化制造程度高，产品远销欧美及东南亚。但当地企业坦言，虽产量大，但多为贴牌生产，利润微薄。

(1) 分析德化陶瓷产业利润微薄现象产生的原因，需要从产业区位条件角度展开调查，请你拟定一份调查内容清单。（列举3项）（3分）

【研学见闻二：景德镇的"景漂"生态】
第二站来到景德镇。这里曾因瓷土枯竭而衰落，后转型为以艺术瓷、高端定制瓷为主的文化创意中心，聚集了数万名来自世界各地的艺术家（被称为"景漂"）。

(2) 请结合调查主题完成访谈调查表的设计。（4分）

景德镇产业发展对人才集聚的影响访谈调查表
| 访谈问题 | 调查目的 |
|---|---|
| "请问您当初选择来到景德镇的原因？" | ① |
| ② | 探究产业协作配套对创意人才集聚的支撑作用 |

【调查数据】研学小组整理了两地陶瓷产业特征对比表。

| 比较维度 | 景德镇 | 德化 |
|---|---|---|
| 主导产品 | 艺术瓷、高端陈设瓷 | 日用瓷、西洋工艺瓷 |

(3) 请结合两地产业特征，论证"竞争将转化为互补"这一观点的合理性。（6分）
```

## 案例6：填空题子问题 — sub_question_type 判断

### 原文

```
27. 阅读材料，完成下列问题。

材料一：生物是在古老的地质历史和特殊的地理环境下长期演化形成的。青藏高原是新构造运动以来，地球上强烈隆起的最高、最年轻的高原。

材料二：受大气环流和地形的共同影响，河谷地区盛行风向随季节发生明显变化。下图为雅鲁藏布江及周边地区略图。

(1) 甲、乙、丙三地物种数量变化趋势是____，解释其自然原因____。
(2) 雅鲁藏布江中游河谷地区冬、夏季盛行风向分别是____风、____风。试分析盛行风冬季强于夏季的原因____。
(3) 野外考察发现，M河段河床上经常会冲刷出新水道，试从自然环境整体性的角度说明原因。
```

### 标准标注

```json
{
  "subquestions": [
    {
      "id": "subq_027_01",
      "label": "(1)",
      "sub_question_type": "mixed",
      "stem": "甲、乙、丙三地物种数量变化趋势是____，解释其自然原因____。"
    },
    {
      "id": "subq_027_02",
      "label": "(2)",
      "sub_question_type": "mixed",
      "stem": "雅鲁藏布江中游河谷地区冬、夏季盛行风向分别是____风、____风。试分析盛行风冬季强于夏季的原因____。"
    },
    {
      "id": "subq_027_03",
      "label": "(3)",
      "sub_question_type": "essay",
      "stem": "野外考察发现，M河段河床上经常会冲刷出新水道，试从自然环境整体性的角度说明原因。"
    }
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **fill_in_blank vs mixed** | "分别是____风、____风" → 简短填空句，`fill_in_blank`；"变化趋势是____，解释其自然原因____" → 有填空+论述，`mixed` | 全标记为 `fill_in_blank` 或全标记为 `essay` |
| **essay 判断** | 不含 `____` 的完整论述问句 → `essay` | 给正常论述题标记 `fill_in_blank` |
| **____ 保留** | 填空空位保留在 `stem` 中，不做替换 | 把 `____` 删除或替换为其他格式 |

## 案例7：图片紧跟特定材料

### 原文

```
6. 阅读材料，完成下列问题。

材料一：福建以山地和丘陵为主，平原只占总面积的10%，是人口和产业的集中分布区。该省是我国的多雨区，降水集中在春夏两季。下图为福建省略图。

材料二：福建是我国水果生产大省，主要在山地和丘陵的坡地栽种水果，易引发水土流失。

(1) 分析福建发展风电比水电更具优势的原因。
(2) 分析甲渔场的自然优势。
(3) 说出福建省果树栽种过程中易引发水土流失的原因。
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **图片紧跟材料一** | "下图为福建省略图"在材料一中 → 图片占位符的 `owner_id` 指向材料一，在材料一内容后渲染 | 把图片放在所有材料结束后（全局位置），或放在材料二后 |
| **材料二无图** | 材料二无图片引用，不创建占位符 | 给材料二也创建占位符 |
| **图片归属材料** | `location_type: "material"` + `owner_id: "material_006_01"` | `location_type: "question_stem"` |
| **材料一有多段时** | 若材料一下有多个段落，"下图为XXX"只出现在第一段 → 占位符仍放在材料一**全部内容末尾**，不放在第一段末尾 | 在"下图为XXX"所在段落末尾就插入占位符，忽略了材料一还有后续段落 |

### 多段材料变体

若材料一有多段：
```
材料一：福建以山地和丘陵为主...下图为福建省略图。
        （材料一第二段）该省海岸线曲折，岛屿众多...
材料二：福建是我国水果生产大省...
```

→ Step2 将材料一的两段合并为一个 material（`content` 包含全部两段文字）
→ Step3 将 `{{image:ph_xxx}}` 放在 material 的 `content` 最末尾（第二段之后），而非第一段末尾

```

(1) 分析巴西吸引中国新能源汽车企业建厂的优势区位条件。（6分）

随着巴西新能源汽车市场的持续扩张，充电设施的合理布局成为亟待解决的关键问题。地理信息系统在问题解决中发挥着重要作用。

(2) 下图示意运用地理信息系统进行充电设施布局的流程。请将"数据存储与管理""人口分布""制图与产品输出""空间综合分析"填写到下面流程图的合适位置。（4分）

巴西汽车市场竞争日益激烈。中国汽车企业面临着诸多挑战：欧美传统汽车强国的竞争压力，当地市场法律法规、消费习惯和中国的差异等。
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **无标记材料边界** | 材料1→(1)→材料2→(2)→材料3→(3)，以子问题作为段落分界 → 拆为3个 `material` | 将三段落合并为1个 material |

| **图片归属材料1** | "下图为巴西区域简图"在材料1中 → 占位符 owner_id 指向 material_016_01 | 把图片放在题目级别 |
