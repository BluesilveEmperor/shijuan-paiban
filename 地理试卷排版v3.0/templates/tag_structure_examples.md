> 供 `tag_structure` (Step2) 参考。每个案例包含"原文"和"标准标注结果"，以及关键判断点的解释。
> AI 在开始识别前应先阅读本文件，理解材料、引导语、子选项、子问题等关键判断规则，然后按相同标准处理当前试卷。

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **材料归属** | "据此完成3~4题"说明材料为3、4题共享，放在第3题的 `materials` 中 | 把材料同时放在第3题和第4题（重复） |
| **引导语分离** | "近年来...据此完成3~4题。" 是引导语句，归入 `guide_sentence`；`content` 只保留材料正文"东兰墨米...富硒农产品。" | 把引导语混入 `content` 或忽略引导语 |
| **引导语范围** | 引导语从引导词（"近年来"）开始到"据此完成3~4题。"结束，不是只有"据此完成3~4题。" | 把整段文字都当成 `content` |
| **子选项识别** | ①②③④ 出现在题干下方、选项上方，是选择组合的子项，提取为 `sub_options`，从 `stem` 中移除 | 把①②③④留在 `stem` 中 |
| **第4题无材料** | 第4题不再重复声明材料，`materials` 为 `[]` | 给第4题也加上相同的材料 |
| **题干不含子选项** | `stem` 到"种植区"为止，不包含①②③④内容 | `stem` = "东兰县...种植区 ①地貌独特 ②水源充足..." |

```json
{
```

```json
  "content": "",
  "guide_sentence": "完成下列要求。",
  "segments": [
    {
      "type": "text",
      "content": "下表为某地区2020-2024年人口迁移数据统计表。"
    },
    {
      "type": "table",
      "data": {
        "rows": 5,
        "cols": 4,
        "data": [
          ["年份", "迁入人口（万人）", "迁出人口（万人）", "净迁移率（%）"],
          ["2020", "12.5", "8.3", "+4.2"],
          ["2021", "15.2", "9.1", "+6.1"],
          ["2022", "18.6", "10.5", "+8.1"],
          ["2023", "22.3", "12.8", "+9.5"]
        ]
      }
    },
    {
      "type": "text",
      "content": "（注：表中数据为年末统计值）"
    }
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **使用 segments** | 材料包含文本+表格+文本的混合内容，必须使用 `segments` 数组 | 把表格强行转成纯文本 |
| **content 为空** | 当使用 `segments` 时，`content` 字段留空 `""` | 同时填写 `content` 和 `segments` |
| **表格含表头** | `rows: 5` 包含表头行，`data` 第一行是表头 | 表头单独处理，`rows: 4` |
| **表格顺序** | 按"文本→表格→文本"的原文出现顺序排列 | 把表格放到最前面 |
| **注释放 segments** | "（注：...）"是表格的补充说明，作为独立的 text segment | 放在表格 data 中 |

## 案例7：注意事项识别与拆分

### 原文

```
注意事项：
1.本试卷共6页，满分100分，时间75分钟。
2.答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。
3.回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。
4.作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。
5.考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。
```

### 标准标注

```json
{
  "notes": "注意事项：1.本试卷共6页，满分100分，时间75分钟。2.答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。3.回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。4.作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。5.考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。",
  "notes_items": [
    {"type": "title", "content": "注意事项"},
    {"type": "item", "number": "1", "content": "本试卷共6页，满分100分，时间75分钟。"},
    {"type": "item", "number": "2", "content": "答卷前，考生务必将自己的姓名和准考证号填写在答题卡上。"},
    {"type": "item", "number": "3", "content": "回答选择题时，选出每小题答案后，用2B铅笔把答题卡上对应题目的答案标号涂黑。如需改动，用橡皮擦干净后，再选涂其他答案标号。涂写在本试卷上无效。"},
    {"type": "item", "number": "4", "content": "作答非选择题时，将答案书写在答题卡上，书写在本试卷上无效。"},
    {"type": "item", "number": "5", "content": "考试结束后，监考员将答题卡按顺序收回，装袋整理；试卷不回收。"}
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **双格式保留** | `notes` 保留原文全文（兼容旧格式），`notes_items` 提供结构化版本 | 只保留一种格式 |
| **标题项** | "注意事项"作为 `{type: "title"}` 项 | 把"注意事项"混入第1条的 `content` |
| **内容不含序号** | `content` 字段不含序号前缀（如"1."），序号在 `number` 字段中 | `content` = "1.本试卷..."（序号重复） |
| **序号在 number 字段** | `number` = "1"、"2"... 为纯数字字符串 | `number` = "(1)" 或缺失 |

## 案例8：分区标题与引导语合并

### 原文

```
一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。
```

### 标准标注

```json
{
  "id": "section_001",
  "type": "选择题",
  "title": "一、选择题：本题共15小题，每小题3分，共45分。在每小题给出的四个选项中，只有一项是符合题目要求的。",
  "instructions": []
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **标题与引导语在同一段** | "在每小题给出的四个选项中..."与题型标题在同一段落，合并到 `title` 字段 | 把"在每小题..."拆到 `instructions` |
| **instructions 为空** | 引导语不单独成段时，`instructions` 为 `[]` | 无论如何都往 `instructions` 里加内容 |

**对比：当引导语单独成段时**：

```
一、选择题：本题共15小题，每小题3分，共45分。

在每小题给出的四个选项中，只有一项是符合题目要求的。
```

此时应标注为：

```json
{
  "title": "一、选择题：本题共15小题，每小题3分，共45分。",
  "instructions": ["在每小题给出的四个选项中，只有一项是符合题目要求的。"]
}
```

## 案例9：非选择题子问题含①②③序号

### 原文

```
(2) 马山县黑山羊销往粤港澳地区较多，主要是因为：
①马山县所在省区与粤港澳地区毗邻，运输距离短，运输成本低
②马山县发展较为滞后，当地黑山羊销售价格与粤港澳地区差异大，将黑山羊销往粤港澳地区______
③粤港澳地区人口众多______，______
```

### 标准标注

```json
{
  "subquestions": [
    {
      "id": "subq_005",
      "label": "(2)-①",
      "stem": "马山县所在省区与粤港澳地区毗邻，运输距离短，运输成本低"
    },
    {
      "id": "subq_006",
      "label": "(2)-②",
      "stem": "马山县发展较为滞后，当地黑山羊销售价格与粤港澳地区差异大，将黑山羊销往粤港澳地区______"
    },
    {
      "id": "subq_007",
      "label": "(2)-③",
      "stem": "粤港澳地区人口众多______，______"
    }
  ]
}
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **①②③拆分为独立子问题** | 每个序号对应一个 `subquestions` 条目 | 把整个段落作为一个子问题 |
| **label 格式** | 父标签+序号：`"(2)-①"`、`"(2)-②"` | `label` = "①"（丢失父级编号） |
| **stem 不含序号** | `stem` 不含①②③序号前缀 | `stem` = "①马山县所在省区..." |
| **填空空位** | `______` 保留在 `stem` 中 | 替换为统一格式或去掉 |

## 汇总：高频判断规则速查

| 场景 | 判断规则 | 归属 |
|------|----------|------|
| "据此完成X~Y题" | 引导语，非材料正文 | `guide_sentence` |
| "阅读图文材料" | 非选择题标准引导语 | `stem` |
| "下图示意..." | 材料正文的一部分 | `content` |
| ①②③④在选择题下方 | 子选项 | `sub_options` |
| ①②③在非选择题子问题中 | 拆分为独立子问题 | `subquestions`，`label` = "(N)-①" |
| 只有一个子问题 | `label` 为空字符串 | `""` |
| "材料一：""材料二：" | 保留在 `content` 中 | `material.content` |
| 注意事项条目 | `content` 不含序号，序号在 `number` 字段 | `notes_items` |
| 引导语与标题同段 | 合并到 `title` | `instructions` 为空 |
| 引导语单独成段 | 写入 `instructions` | `instructions` = ["引导语"] |
