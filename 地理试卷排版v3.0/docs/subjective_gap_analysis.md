# 主观题案例缺口分析报告

> 基于 `templates/主观题案例补充说明.txt` 中 6 个真实主观题场景的对照分析。
> 日期：2026-07-10

---

## 一、案例速览与缺口分类

| 案例 | 核心场景 | 当前能否处理 | 缺口等级 |
|------|---------|-------------|---------|
| 25题 | 材料含表格+图片，图片/表格紧跟各自材料 | 能（segments + owner_id 已覆盖） | 无 |
| 28题 | **新题型**：子问题穿插于材料之间 + 子问题含表格 + 非标准材料标题 | **不能** | **CRITICAL** |
| 27题 | 主观题中的填空题（`____` 空位） | 部分能（文本保留，但无语义标记） | LOW |
| 6题 | 图片在材料一后（非全局位置） | 能（owner_id 确定材料归属） | 无 |
| 27题② | 材料文字提3张图、实际2张（合并） | 能（Step4 图片分析已覆盖） | 无 |
| 16题 | 材料与子问题交替出现 + 无标题标记的材料段落 | **不能** | **CRITICAL** |

---

## 二、CRITICAL 缺口详解

### 缺口 1：材料与子问题交错排列

**问题描述**：

当前 Schema 将 `materials` 和 `subquestions` 分为两个独立的平铺数组：

```json
{
  "materials": [
    {"id": "mat_001", "content": "材料一..."},
    {"id": "mat_002", "content": "材料二..."},
    {"id": "mat_003", "content": "材料三..."}
  ],
  "subquestions": [
    {"id": "subq_001", "label": "(1)", "stem": "..."},
    {"id": "subq_002", "label": "(2)", "stem": "..."},
    {"id": "subq_003", "label": "(3)", "stem": "..."}
  ]
}
```

排版时按"所有材料 → 所有子问题"的顺序渲染。但真实试卷中，材料和子问题是交替出现的：

**28题原文结构**：
```
【研学背景】                 ← 材料1
【研学见闻一：德化】          ← 材料2
(1) 分析德化陶瓷...           ← 子问题(1) 紧接材料2之后
【研学见闻二：景德镇】        ← 材料3
(2) 访谈调查表设计            ← 子问题(2) 紧接材料3之后
【调查数据】                  ← 材料4
(3) 论证融合发展的合理性       ← 子问题(3)
```

**16题原文结构**：
```
材料1（巴西汽车 + 图片）      ← 材料1
(1) 分析优势区位条件           ← 子问题(1)
材料2（充电设施布局）          ← 材料2（无标记）
(2) 填写流程图                 ← 子问题(2)
材料3（市场竞争）              ← 材料3（无标记）
(3) 开拓本地市场措施           ← 子问题(3)
```

**影响**：
- 排版时无法恢复试卷原始的交错顺序
- 材料2在原文中紧邻子问题(1)，排版时却出现在所有材料的最前面
- 考生阅读体验与原始试卷不一致

### 缺口 2：子问题不能持有自己的材料/表格

**问题描述**：

当前 Schema 中 `subquestion_item` 仅包含 `id`、`label`、`stem` 三个字段。但实际试卷中存在子问题自带材料的情况：

**28题(2) 访谈调查表**：
```
(2) 请结合调查主题完成访谈调查表的设计。

"景德镇产业发展对人才集聚的影响"访谈调查表
┌─────────────────────────────┬────────────────────────┐
│ 访谈问题                     │ 调查目的                │
├─────────────────────────────┼────────────────────────┤
│ "请问您当初选择来到景德镇..."  │ ①                      │
│ ②                           │ 探究完善产业协作配套...   │
│ "您认为景德镇城市产业转型..."  │ 调查城市产业转型...      │
└─────────────────────────────┴────────────────────────┘
```

这个表格是子问题(2)的一部分，不是共享材料。当前 Schema 无法表达"子问题专属表格"。

**28题(3) 【调查数据】+ 产业对比表**：
```
【调查数据】研学小组整理了两地陶瓷产业特征对比表。

┌──────────┬──────────────┬──────────────┐
│ 比较维度  │ 景德镇        │ 德化          │
├──────────┼──────────────┼──────────────┤
│ 主导产品  │ 艺术瓷...     │ 日用瓷...     │
│ 生产方式  │ 手工拉坯...   │ 机器注浆...   │
└──────────┴──────────────┴──────────────┘

(3) 有专家在研学总结会上提出...
```

【调查数据】是一段材料文字 + 一个表格，它紧邻子问题(3)。如果按交错排列（缺口1），这可以放在问题级 materials 中；但如果希望它仅服务于子问题(3)，就需要子问题级 materials。

---

### 缺口 3：无标记材料的段落边界识别

**问题描述**：

16题中第二段和第三段材料没有"材料一""材料二"标记，仅通过段落空行分隔：

```
材料1: "目前，新能源纯电动汽车...下图为巴西区域简图。" [有图片标记]
(1) 分析巴西吸引...
材料2: "随着巴西新能源汽车市场...发挥着重要作用。"          ← 无"材料X"标记
(2) 下图示意...填写到下面流程图的合适位置。                   [有图片标记]
材料3: "巴西汽车市场竞争日益激烈...和中国的差异等。"          ← 无"材料X"标记
(3) 简述中国新能源汽车企业在巴西...
```

当前 Step2 依赖"材料一：""材料二："等标记来拆分材料段落。无标记时可能：
- 将三段落合并为一个巨大 material
- 误将第二段当成子问题(1)的延伸文本

## 三、NON-CRITICAL 可处理场景（确认无缺口）

以下场景当前系统已能处理，无需改动：

### 3.1 25题：材料含表格+图片（已支持）

- 表格 → `material.segments[].type: "table"` ✓
- 图片 → `placeholder.location_type: "material"` + `owner_id: material_xxx` ✓
- 材料标题（"材料一：""材料二："）→ `content` 保留标题文本 ✓

### 3.2 6题：图片紧跟特定材料（已支持）

- 图片在材料一之后 → `placeholder.location_type: "material"`, `owner_id` 指向材料一 ✓
- 材料二无图片 → 无占位符 ✓

### 3.3 27题②：材料图片合并判断（已覆盖）

- "图2、图3"两张图合并为一张 → Step4 图片分析 + Step3 合并检测 ✓

### 3.4 27题①：填空题空位（已基本支持）

- `____` 保留在 `stem` 文本中 → 已处理 ✓
- 排版时可根据 `____` 自动渲染填空线 → 排版层可处理 ✓
- 但无语义标记区分"论述题"和"填空题" → 见 LOW 缺口

## 四、LOW 缺口：填空式子问题语义缺失

**问题描述**：

27题中有典型的填空题子问题：
```
(1) 甲、乙、丙三地物种数量变化趋势是____，解释其自然原因____。
(2) 雅鲁藏布江中游河谷地区冬、夏季盛行风向分别是____风、____风。
```

当前 stem 仅作为纯文本保留 `____`。但排版层需要知道"这是一个填空式子问题"以便：
- 在 `____` 处渲染下划线填空区域
- 设置合适的行间距（填空区域需要更多垂直空间）

建议：为 subquestion 增加可选的 `sub_question_type` 字段。

## 五、推荐技术方案

### 方案总览

| 缺口 | 方案 | 改动范围 | 向后兼容 |
|------|------|---------|---------|
| 缺口1：交错排列 | material + subquestion 增加可选 `order` 字段 | Schema + Step2 + 排版 | 是（无 order = 当前行为） |
| 缺口2：子问题材料 | subquestion 增加可选 `materials` 数组 | Schema + Step2 + 排版 | 是（无 materials = 当前行为） |
| 缺口3：无标记边界 | Step2 增加段落语义边界检测规则 | Step2 SKILL.md | 是（新规则追加） |
| 缺口4：填空标记 | subquestion 增加可选 `sub_question_type` | Schema + Step2 | 是（无 = "essay"） |

### 方案 5.1：解决缺口1 — 交错排列

**Schema 变更**：为 `material` 和 `subquestion_item` 各增加 `order` 字段。

```json
// material 增加:
"order": {
  "type": "integer",
  "description": "在题目内的渲染顺序（1-based），与 subquestions 的 order 混合排序后得到最终渲染序列"
}

// subquestion_item 增加:
"order": {
  "type": "integer",
  "description": "在题目内的渲染顺序（1-based），与 materials 的 order 混合排序后得到最终渲染序列"
}
```

**示例（28题）**：
```json
{
  "materials": [
    {"id": "mat_001", "order": 1, "content": "【研学背景】..."},
    {"id": "mat_002", "order": 2, "content": "【研学见闻一：德化】..."},
    {"id": "mat_003", "order": 4, "content": "【研学见闻二：景德镇】..."},
    {"id": "mat_004", "order": 6, "content": "【调查数据】..."}
  ],
  "subquestions": [
    {"id": "subq_001", "order": 3, "label": "(1)", "stem": "..."},
    {"id": "subq_002", "order": 5, "label": "(2)", "stem": "..."},
    {"id": "subq_003", "order": 7, "label": "(3)", "stem": "..."}
  ]
}
```

排版时混合排序 → 渲染序列：mat_001 → mat_002 → subq_001 → mat_003 → subq_002 → mat_004 → subq_003

**为什么选 `order` 而不是 `content_sequence`**：
- `order` 是最小侵入性改动（每个对象加1个可选整数）
- `content_sequence` 需要新增一个顶层数组字段，改动面更大
- `order` 在无交错时自动回退到当前行为（materials 按数组顺序，subquestions 按数组顺序）

### 方案 5.2：解决缺口2 — 子问题材料

**Schema 变更**：为 `subquestion_item` 增加可选的 `materials` 数组。

```json
// subquestion_item 增加:
"materials": {
  "type": "array",
  "description": "子问题专属材料（如表格、图片等）。与问题级 materials 结构相同，但仅服务于该子问题。",
  "items": { "$ref": "#/definitions/question/properties/materials/items" }
}
```

**示例（28题(2)）**：
```json
{
  "id": "subq_002",
  "label": "(2)",
  "stem": "请结合调查主题完成访谈调查表的设计。（4分）",
  "order": 5,
  "materials": [
    {
      "id": "material_015",
      "content": ""景德镇产业发展对人才集聚的影响"访谈调查表",
      "guide_sentence": "",
      "segments": [
        {
          "type": "table",
          "data": {
            "rows": 4,
            "cols": 2,
            "header": ["访谈问题", "调查目的"],
            "data": [
              ["请问您当初选择来到景德镇...", "①"],
              ["②", "探究完善的产业协作...对创意人才集聚的支撑作用。"],
              ["您认为景德镇城市产业转型...", "调查城市产业转型..."]
            ]
          }
        }
      ]
    }
  ]
}
```

### 方案 5.3：解决缺口3 — 无标记材料边界检测

**Step2 tag_structure/SKILL.md 修改**：在"材料拆分规则"中增加以下内容：

```
**规则4：无标记材料的段落边界检测**

当段落之间没有"材料一""材料二"等显式标记时，按以下优先级判断是否拆分为独立材料：

1. **子问题位置作为分界**：若段落A与段落B之间夹着一个子问题 → 段落A和段落B是独立材料
   例：段落1 → (1)题 → 段落2 → (2)题 → "段落1"和"段落2"是两个独立材料

2. **话题突变检测**：若连续两段讲述了明显不同的话题/区域/对象 → 可能为独立材料
   例：段落1讲"巴西汽车产业概况" → 段落2讲"充电设施布局" → 两个独立材料

3. **"下图""图X"作为材料尾部标记**：若段落末尾出现"下图为..."且下一段无子问题分隔 → 该图片是当前材料的附属，不拆分材料
   例：段落1末尾"下图为巴西区域简图。" + 图片 + 段落2 → 图片紧跟段落1，段落2是独立材料

4. **保守策略**：不确定时合并为一个大材料，标记 `uncertain: true`，在 `notes` 中注明疑似边界位置
```

### 方案 5.4：解决缺口4 — 填空题语义标记

**Schema 变更**：为 `subquestion_item` 增加可选的 `sub_question_type`。

```json
"sub_question_type": {
  "type": "string",
  "enum": ["essay", "fill_in_blank", "mixed"],
  "default": "essay",
  "description": "子问题类型：essay=论述题，fill_in_blank=填空题，mixed=混合型"
}
```

**Step2 判断规则**：
- stem 中包含 `____` 或 `______` 且总长度 < 50字 → `fill_in_blank`
- stem 中同时包含 `____` 和完整问句 → `mixed`
- 其他情况 → `essay`

## 六、改动清单

### 6.1 Schema 变更（exam_paper.schema.json）

| 位置 | 变更 | 类型 |
|------|------|------|
| `definitions.question.properties.materials.items` | + `order` (optional integer) | 新增字段 |
| `definitions.question.properties.subquestions.items` | + `order` (optional integer) | 新增字段 |
| `definitions.question.properties.subquestions.items` | + `materials` (optional array, ref materials) | 新增字段 |
| `definitions.question.properties.subquestions.items` | + `sub_question_type` (optional enum) | 新增字段 |

**总增量**：4 个可选字段，Schema 向后兼容。

### 6.2 Skill 变更

| 文件 | 变更内容 |
|------|---------|
| `tag_structure/SKILL.md` | 增加无标记材料边界检测规则（方案 5.3）；增加交错排列的 order 赋值规则；增加子问题材料归属规则；增加填空题类型判断 |

| 变更 | 说明 |

| 渲染顺序读取 `order` 字段 | 若有 order，混合排序 materials + subquestions；若无，保持当前行为 |

## 七、优先级建议

| 优先级 | 缺口 | 理由 |
|--------|------|------|
| P0 | 缺口1：交错排列 | 影响 2/6 案例（28题、16题），排版顺序错误是严重缺陷 |
| P0 | 缺口3：无标记边界 | 与缺口1关联，不解决则材料拆分错误 |
| P1 | 缺口2：子问题材料 | 影响 1/6 案例（28题），但可用 workaround（把表格放问题级 materials，用 order 紧邻子问题） |
| P2 | 缺口4：填空标记 | 影响体验但不阻塞排版，可在 Step2 中标记，排版层后续处理 |
