## 一、Schema 层修复

### 修复项1：新增选择题子选项（sub_options）字段

**关联问题**：问题4

**根因**：Schema 缺少选择题子选项的定义，导致 `tag_structure` 无法正确识别和存储①②③④类型的子选项。

**修改文件**：[schemas/exam_paper.schema.json](file:///C:/Users/Deledy/Desktop/GeoPaperFormat/地理试卷排版v3.0/schemas/exam_paper.schema.json)

**修改内容**：在 `definitions.question.properties` 中新增 `sub_options` 字段：

```json
"sub_options": {
  "type": "array",
  "description": "选择题子选项列表（如①②③④）",
  "items": {
    "type": "object",
    "required": ["label", "text"],
    "properties": {
      "label": {
        "type": "string",
        "description": "子选项标签，如'①'、'②'"
      },
      "text": {
        "type": "string",
        "description": "子选项内容"
      }
    },
    "additionalProperties": false
  }
}
```

**修改位置**：在 `options` 字段之后、`subquestions` 字段之前（约第344行）。

**验证方法**：执行 `python scripts/validate_json.py --schema schemas/exam_paper.schema.json --json output/xxx/试卷数据/final_exam.json`

## 二、SKILL 指令层修复

### 修复项2：修正题型标题与说明的识别规则

**关联问题**：问题1

**根因**：`tag_structure` SKILL 的示例误导 AI 将标题后半部分（"在每小题给出的四个选项中..."）错误提取为说明。

**修改文件**：[.trae/skills/tag_structure/SKILL.md](file:///C:/Users/Deledy/Desktop/GeoPaperFormat/地理试卷排版v3.0/.trae/skills/tag_structure/SKILL.md)

**修改内容**：

1. **第69行**（`instructions` 定义）：将说明改为：
   ```
   `instructions`：分区引导语/说明（单独成段的说明文字，如'考试时间90分钟'）
   ```

2. **新增识别规则**（在"分区边界"规则后，约第110行）：
   ```
   **题型标题合并规则**：
   - 当"在每小题给出的四个选项中..."与题型标题（如"一、选择题..."）在**同一段落**时，应合并到 `title` 字段中，不应提取为 `instructions`

3. **输出示例**（约第159行）：将示例修改为：
   ```json

### 修复项3：强化中文弯引号的处理规则

**关联问题**：问题3

**根因**：`tag_structure` SKILL 虽然有弯引号处理规则，但约束力度不够，AI 执行者仍可能在生成 Python 脚本时使用中文弯引号导致字符破坏。

**修改文件**：[.trae/skills/tag_structure/SKILL.md](file:///C:/Users/Deledy/Desktop/GeoPaperFormat/地理试卷排版v3.0/.trae/skills/tag_structure/SKILL.md)

**修改内容**：

1. **在「Python 源文件中文字符串警告」章节后（约第256行）新增强制约束**：
   ```
   **强制要求**：所有包含中文文本的字符串必须使用方案1（Unicode 转义）处理中文弯引号。在生成 Python 脚本时，必须先定义以下常量：
   
   ```python
   LQ = '\u201c'  # 左弯引号 "
   RQ = '\u201d'  # 右弯引号 "
   ```
   
   然后在所有包含中文弯引号的字符串中使用 `{LQ}` 和 `{RQ}` 替代：
   ```python
   stem = f"紫花苜蓿被称为{LQ}牧草之王{RQ}的主要原因是（）"
   ```
   ```

2. **在「输出后自检清单」中增加弯引号检查**（约第297行）：
   ```
   - [ ] **中文弯引号正确处理**：检查所有包含中文文本的字段（如 `stem`、`text`），确认中文弯引号（""）正确显示，未被转换为 ASCII 引号（""）
   ```

**验证方法**：重新执行 `tag_structure` 后检查生成的 Python 脚本，确认所有中文弯引号都使用了 Unicode 转义。

   ```python
   def _format_subquestions(doc, question, logger, quality):
       """排版非选择题子问题。"""
       subquestions = question.get('subquestions', [])
       for sq in subquestions:
           label = sq.get('label', '')
           stem = sq.get('stem', '')
           formatted = FILL_IN_BLANK_PATTERN.sub('______', stem)
           if formatted != stem:
               quality['fill_in_blank_count'] += 1
           p = doc.add_paragraph()
           apply_style(p, 'Normal')
           # 只有当 label 不为空时才显示编号
           if label:
               add_mixed_text(p, f'{label} {formatted}', cn_font='宋体')
           else:
               add_mixed_text(p, formatted, cn_font='宋体')
   ```

## 六、潜在风险提示

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| Schema 修改影响已有 JSON | 旧的 JSON 文件可能不符合新 Schema | 修改 Schema 时使用新增字段而非修改已有字段 |
| SKILL 修改后 AI 理解偏差 | AI 可能仍不遵守新规则 | 在 SKILL 中增加自检步骤和明确的输出示例 |
| 子选项识别过度 | 可能误将非子选项的①②③④识别为子选项 | 在规则中增加上下文判断条件 |
| 图片占位符位置不准确 | 图片可能插错位置 | 在 `tag_placeholders` 中增加标记位置的验证 |
