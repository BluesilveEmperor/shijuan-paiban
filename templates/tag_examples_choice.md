# 选择题打标案例

> 供 `tag_structure` (Step2) 在处理**选择题**时参考。
> **触发条件**：试卷包含选择题分区（`section.type = "选择题"`）。
> 包含：共享材料识别、引导语分离、子选项提取、"下图"类材料的处理。

## 案例1：选择题组 — 共享材料 + 引导语 + 子选项

### 原文

```
东兰墨米耐阴凉，主要种植在广西东兰县的喀斯特山区，属于富硒农产品。近年来，当地推行"党支部+合作社+农户"发展模式，推动了墨米产业的发展。据此完成3~4题。

3. 东兰县成为特色墨米产区，主要得益于种植区

A. ①②   B. ②④   C. ①③   D. ③④
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **材料归属** | "据此完成3~4题"说明材料为3、4题共享，放在第3题的 `materials` 中 | 把材料同时放在第3题和第4题（重复） |
| **引导语分离** | "近年来...据此完成3~4题。" 是引导语句，归入 `guide_sentence`；`content` 只保留材料正文"东兰墨米...富硒农产品。" | 把引导语混入 `content` 或忽略引导语 |
| **引导语范围** | 引导语从引导词（"近年来"）开始到"据此完成3~4题。"结束，不是只有"据此完成3~4题。" | 把整段文字都当成 `content` |
| **子选项识别** | ①②③④ 出现在题干下方、选项上方，是选择组合的子项，提取为 `sub_options`，从 `stem` 中移除 | 把①②③④留在 `stem` 中 |
| **第4题无材料** | 第4题不再重复声明材料，`materials` 为 `[]` | 给第4题也加上相同的材料 |
| **题干不含子选项** | `stem` 到"种植区"为止，不包含①②③④内容 | `stem` = "东兰县...种植区 ①地貌独特 ②水源充足..." |

## 案例5：题目级图片无文字引用

### 原文

```
坐落于地堑谷地一侧的某山脉是开展地理研学活动的理想场所。某学校组织学生从山脚下的P地（34°8'20"N，107°52'53"E）登山开展考察。下图为学生绘制的山地垂直自然带简图。完成下面小题。

【图片位置】

13. P地有著名的天然温泉，与其直接相关的是（   ）
A. 褶皱	B. 沉积作用	C. 断层	D. 火山喷发

14. 学生在考察过程中拍摄的植被景观照片与垂直自然带对应正确的是（   ）

【图片位置】

A. 甲①      乙②      丙③      丁④	B. 甲④      乙①      丙②      丁③
C. 甲④      乙③      丙②      丁①	D. 甲④      乙②      丙①      丁③
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **材料级图片** | "下图为...垂直自然带简图" → 图片归属于材料，Step3 在材料节点创建占位符 | 把材料图片归属给第13题或第14题 |
| **题目级图片无文字引用** | 第14题题干没有任何关于图片的描述，但题干下方出现图片 → 需要通过 `content.md` 中的 `{{image:img_xxx}}` 标记或 `image_manifest.json` 的 paragraph_index 来判断图片位置 | 因为题干没提到图片就跳过，不创建占位符 |
| **图片归属判断** | 根据图片标记在 `content.md` 中的位置：紧跟第14题题干之后 → 归属于第14题（`location_type: "question_stem"`） | 不判断归属，随意放置 |

## 案例6：题目引用材料级图片（非自身独立图片）

### 原文

```
2025年5月，新型零碳动态遮阳系统在意大利威尼斯（45°26'N，12°20'E）展出。该系统由六根拱架支撑，朝向正午太阳倾斜，三角面板随阳光强弱自动启闭。其外形设计灵感来自当地太阳视运动轨迹，边缘两个拱架分别代表夏至日与冬至日。下图为该遮阳系统照片。据此完成13-15题。

【图片位置】

13．拍摄该照片时，朝向
A．东南	B．东北	C．西南	D．西北

14．环形拱架④代表的日期接近
A．清明（4月5日前后）	B．立春（2月4日前后）
C．小暑（7月7日前后）	D．立冬（11月7日前后）

15．拱架①与地平面的夹角最接近
A．21°		B．23.5°		C．44.5°		D．68°
```

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **15题引用材料图片** | 15题问"拱架①与地平面的夹角"，需要查看材料中的遮阳系统照片来判断。图片归属于材料，15题没有独立图片 | 因为15题需要看图，就给15题也创建一个占位符 |
| **整组共享一张图** | 材料中"下图为该遮阳系统照片"说明只有1张图片，13/14/15题共享 | 为每道题各创建一个占位符指向同一张图 |
| **重复引用处理** | 若多道题都需要同一张图片，只在材料节点创建1个占位符，不在各题重复创建 | 13/14/15题各创建1个相同图片的占位符 |

## 案例7：选项含图片

### 原文

```
下图为北半球某地某时刻海平面等压线图（单位hPa）。完成下面小题。

【图片位置】

22. 图中等压距和P地气压值（单位hPa）可能是（   ）
A. 5.0、1012	B. 7.5、1008	C. 5.0、1027	D. 7.5、1030

23. 甲、乙、丙、丁四地气象要素的垂直变化，可能出现的是（   ）
A. 【图片位置】	B. 【图片位置】	C. 【图片位置】	D. 【图片位置】
```

> 注：23题的四个选项（A/B/C/D）各包含一张图片（气温/气压垂直变化示意图），`content.md` 中表现为选项文字旁有 `{{image:img_xxx}}` 标记。

### 关键判断

| 判断点 | 正确做法 | 常见错误 |
|--------|----------|----------|
| **选项图片识别** | `content.md` 中选项文字旁有图片标记 → 该选项本身是图片，创建占位符时 `location_type: "option"` | 忽略选项中的图片标记 |
| **选项图片归属** | 选项图片归属于该题目（`owner_id` 为 `question.id`），而非材料 | 创建在材料节点下 |
| **多选项图片** | 4个选项各含图片 → 创建4个占位符，分别对应 A/B/C/D | 只创建1个占位符或全部忽略 |
